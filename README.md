En este trabajo abordamos el problema de estimar el precio de vehículos tipo SUV en el mercado automotor argentino,
utilizando técnicas de aprendizaje automático supervisado sobre datos reales. A partir de un conjunto de datos compuesto
por características técnicas, estéticas y comerciales de miles de vehículos, entrenamos y comparamos múltiples modelos de
aprendizaje, incluyendo regresión lineal, Random Forest, XGBoost y redes neuronales (MLP). Se realiza un análisis exhaustivo del
preprocesamiento de datos, tratamiento de valores faltantes, codificación de variables categóricas e ingeniería de features.
